# 🛡️ CYBERNEX

### Cybersecurity Command Center

CYBERNEX is a modern cybersecurity platform featuring interactive security tools, ethical hacking resources, networking utilities, and beginner-friendly tutorials.

## 🚀 Features

- 🔐 Password Strength Checker
- #️⃣ SHA-256 Hash Generator
- 🔄 Base64 Encoder & Decoder
- 🌐 URL Encoder & Decoder
- 📡 Public IP Lookup
- 🧩 JSON Formatter
- 🖥️ Computer Networking Tutorials
- 🐧 Linux Fundamentals
- 🛡️ Ethical Hacking Education
- 🔍 Web Security Learning

## 💻 Installation

1. Clone this repository:

```bash
git clone https://github.com/USERNAME/CYBERNEX.git
```

2. Open the project folder.
3. Open `index.html` in your browser.

For full Web Crypto API support, run through localhost or HTTPS.

## 🔒 Security & Disclaimer

CYBERNEX is designed for educational and informational purposes.

- Use security tools responsibly.
- Never test systems without authorization.
- Do not enter real passwords into demonstration tools.
